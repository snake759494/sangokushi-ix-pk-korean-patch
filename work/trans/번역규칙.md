# 삼국지9 PK (PS2) 한글화 번역 규칙

이 규칙은 초반부 테스트 번역(2026-09-18)을 하면서 정했고, 전체 번역을 시작하면서 보강했다. 모든 번역은 이 규칙을 따르고, 새로 정한 규칙은 여기에 추가한다.
**기계번역 금지.** 번역기·사전 자동 치환을 쓰지 않는다. 모든 문장은 원문의 뜻과 화면 상황, 말하는 사람을 생각하며 사람이 직접 옮긴다. 원문의 정보(인물·사건·수치·인과관계·조건)는 빼거나 더하지 않는다.

## 1. 기술 제약 (지키지 않으면 깨지거나 빌드가 거부됨)

| 항목 | 규칙 |
|---|---|
| 한글 | **KS X 1001 완성형 2,350자만** 사용 (폰트의 亜~美 슬롯에 입힘). `똠, 햏, 뷁, 쌰, 쏠(○), 챠(○)` 같은 글자 중 완성형에 없는 것은 쓸 수 없다. 검사기가 알려 주면 다른 말로 바꾼다 |
| 한자·가나 | 번역문에 쓰지 않는다. 한자 슬롯이 한글로 바뀌어 있어서, 한자를 쓰면 엉뚱한 한글이 나온다. 괄호 속 한자 병기도 안 된다 |
| 문장부호 | 반각 `, . ! ? : ( ) ~ -`를 쓴다. 일본식 `、 。`는 쓰지 않는다. 낫표·겹낫표(`「」『』`), 가운뎃점(`・`), `＜＞`, `【】`, `／`, `……`, `○ × △ →`, 원문자(`①②`)는 원문과 같은 자리에서 그대로 써도 된다 |
| 숫자 | 반각 숫자(`1 2 3`)를 쓴다 (원문이 전각 `１２３`이어도 반각으로. 폭이 절반이다) |
| 띄어쓰기 | 한글 맞춤법대로 띄운다. 공백은 반각 1칸이다. 들여쓰기에는 원문과 같이 전각 공백 `　`을 쓴다. 번역 파일에서 줄 끝 공백이 꼭 필요하면 `⎵`로 적는다 |
| 제어 태그 | `{V:..}`(이름·숫자 변수), `{C:..}`(글자 색), `{U:F0B0}` 이상(버튼 아이콘), `{X:..}`는 **지우거나 새로 만들지 않는다**. 순서는 한국어 어순에 맞게 옮겨도 된다. 색 태그는 원문에서 강조했던 낱말을 감싸도록 옮긴다(`{C:16b}兵法{C:32b}` → `{C:16b}병법{C:32b}`). 변수는 문장상 꼭 필요 없으면 뺄 수 있지만(경고만 나옴) 되도록 살린다 |
| 한자 글리프 태그 | `{U:F040}`~`{U:F0AB}`, `{S:....}`는 게임 전용 한자(龐, 郃 등)·가나다. 번역문에는 한글로 풀어 쓴다(`{U:F04C}統` → 방통) |
| 줄바꿈 | 번역 파일에서는 `⏎`로 적는다 |

### 1.1 변수 `{V:..}` 뒤의 조사 (가장 중요)

변수에는 게임 중에 이름·지명 등이 들어간다. 받침이 있는지 알 수 없으므로 **변수 바로 뒤에 받침에 따라 모양이 바뀌는 조사를 붙이지 않는다.**
검사기가 막는 것: 변수 바로 뒤의 `을 를 이 가 은 는 과 와 로 으로 나 이나 야 아 여 라 란 랑 였`.
`을(를)` 같은 병기도 쓰지 않는다.

쓸 수 있는 방법 (자연스러운 것을 고른다):
1. **받침과 상관없는 조사**: `의 에 에게 에서 께 께서 도 만 까지 부터 에게서 한테 보다 처럼 같이 마저 조차`
   예) `{V:02DA}께서 허락하셨습니다`, `{V:3DAB}에서 반란이`, `{V:01DA}의 부대가`, `{V:01DA}에게 {V:1543} 하사`
2. **말을 덧붙여 받침을 고정**: `{V:1FC7}군은`, `{V:02DA} 님은`, `{V:02DA} 공이`, `{V:01DA} 장군이`(무장이 확실할 때), `{V:3DAC} 쪽은`, `{V:4761} 병법을`, `{V:1543} 아이템을`
3. **어순·구조 바꾸기**: `{V:3DAC}を撤去します` → `{V:3DAC}의 철거를 명합니다` / `{V:3DAC} 철거!`,
   `{V:01DA}が討死しました` → `{V:01DA}, 전사했습니다` 대신 `{V:01DA} 장군이 전사했습니다` 또는 `전사: {V:01DA}` 처럼 상황에 맞게
4. **쉼표로 부르기·제시**: `{V:02DA}, 각오하라!`, `{V:3DAB}, 그곳을 치겠습니다`
5. 시스템 메시지는 명사형 끝맺음도 된다: `{V:01DA}에게 {V:1543} 수여`, `{V:3DA2} 민심 상승`

변수의 뜻 (원문 문맥으로 확인할 것)

| 변수 | 들어가는 것 |
|---|---|
| `{V:01DA}` `{V:02DA}` `{V:03DA}` `{V:04DA}` `{V:05DA}` | 무장 이름 (성명). `{V:02DA}殿`은 대개 상대 군주·주군 |
| `{V:01DB}` `{V:02DB}` `{V:03DB}` | 성, `{V:01DC}` `{V:03DC}` 이름, `{V:01DD}` `{V:02DD}` `{V:03DD}` 자(字) 또는 부르는 이름 |
| `{V:1FC7}` `{V:20C7}` `{V:01DE}` | 세력 이름(군주 이름. `{V:1FC7}軍` = `{V:1FC7}군`) |
| `{V:1FC9}` | 군주 이름, `{V:1FC8}` 작위, `{V:1FCB}` `{V:1FCE}` 군단 이름, `{V:20C9}` 연합 이름 |
| `{V:3DA2}` `{V:3DAB}` `{V:3DAC}` `{V:3DA3}` `{V:3D3F}` `{V:3EAB}` `{V:3EAC}` `{V:01E0}` | 도시·시설 이름 |
| `{V:337A}` | 부대 이름(대장 이름) |
| `{V:4761}` | 병법 이름, `{V:1543}` 아이템 이름 |
| `{V:65}` `{V:66}` `{V:67}` `{V:68}` `{V:7C}` | 숫자. 뒤에 단위를 붙인다(`{V:65}명`, `{V:65}개`). 숫자 뒤에도 받침 조사는 붙이지 않는다 |
| `{V:D5}年{V:D7}月` | 연·월 숫자 → `{V:D5}년 {V:D7}월` |

### 1.2 화면별 폭·줄 수 한계

폭은 반각 단위로 센다(한글·전각 = 2, 반각·공백 = 1, `{V:..}` = 8, 아이콘 = 2, 색 태그 = 0). 게임 글자 간격은 전각 22px, 반각 11px이다.
각 단위의 한계는 작업 파일의 머리(`[dlg 폭28 3줄]` 등)에 적혀 있고 `check_job.py`가 검사한다.

| 종류 | 화면 | 한 줄 최대 | 줄 수 |
|---|---|---|---|
| `dlg` | 인물 대사창·이벤트 대사·시스템 메시지 | 28 (한글 14자). **변수가 없는** 원문 줄이 더 길면 그 폭까지(변수 든 줄은 변수 8칸으로 계산). 에뮬레이터 확인: 30칸 줄은 대사창 오른쪽 장식에 잘린다 | **원문과 같은 줄 수**. 대사창은 3줄마다 페이지가 넘어가므로 줄 수가 바뀌면 페이지가 어긋난다. 원문의 빈 줄은 같은 자리에 둔다 |
| `help` | 도움말·용어사전 본문 한 쪽 | 34 (한글 17자) + 줄 끝 문장부호 1개 | 13줄 이하. 줄바꿈 위치는 자유. `＜제목＞` 줄과 문단 구성은 원문대로 |
| `desc` | 시나리오·챌린지 개요 | 30 (한글 15자) + 줄 끝 문장부호 1개 | 13줄 이하. 줄바꿈 위치는 자유 |
| `bar` | 화면 하단 한 줄 도움말 | 52 (26자) | 1줄 |
| `msg` | 그 밖의 한 줄 메시지 | 작업 파일에 적힌 폭 | 1줄 |
| `bio` | 무장 열전 (M_RTDN) | 36 (18자). 원문도 줄 끝 걸침이 없으므로 문장부호까지 36 이내 | 4줄 이하 |
| `label` `name` | 메뉴·버튼·표 머리글·이름 | 원문 폭 (같은 목록에 더 긴 항목이 있으면 그 폭) | 1줄 |
| ELF 문자열 | 실행파일 속 메뉴·라벨 | 원문 폭 이하, **바이트 수 ≤ 원문 슬롯** | 1줄 |

**줄 끝 문장부호 걸침**: 원문 개요·도움말은 한 줄을 꽉 채운 뒤 `、。`만 다음 칸에 걸친다. 한글도 같다: 본문은 폭까지, 줄 끝의 `. , ! ? 」 』 )` 하나만 더 걸칠 수 있다.

**줄바꿈 방법**: 어절(띄어쓰기) 단위로만 줄을 바꾼다. 낱말 가운데서 끊지 않는다. 도움말에서 문단이 전각 공백 `　`으로 시작하면 이어지는 줄도 `　`으로 시작한다(원문 방식). 넘치면 조사·어미·중복 표현을 줄이고, 정보는 빼지 않는다.

**대사 줄 나누기**: 원문 한 줄을 번역 한 줄에 대응시키는 것이 기본이다. 한국어 어순 때문에 어려우면 같은 페이지(3줄) 안에서 내용을 옮겨도 되지만 줄 수는 원문과 같아야 한다.

## 2. 문체

| 원문 | 한국어 | 예 |
|---|---|---|
| 메뉴 항목 (`〜を始める`, `〜する`) | 명사형 | 新しくゲームを始める → 새 게임 시작 |
| 하단 도움말 (`〜します`, `〜してください`) | 합쇼체 `~합니다`, `~하십시오` | 新しくゲームを始めます → 새 게임을 시작합니다 |
| 도움말·용어사전 본문 (です・ます) | 합쇼체 | ゲームの時代設定です → 게임의 시대 설정입니다 |
| 시나리오 개요 (だ・である 체) | 해라체 평서문 `~한다`, `~했다` | ゲームは始まる → 게임이 시작된다 |
| 무장 열전 | 해라체 서술 `~했다`, `~이다`. 폭이 모자라면 `~함`, 명사 끝맺음도 된다 | 劉備に仕えた → 유비를 섬겼다 |
| 시스템 확인 (`よろしいですか？`) | `~하시겠습니까?` | |
| 시스템 알림 (`〜しました`) | `~했습니다` (좁으면 명사형 `~ 완료`) | |
| 승리·패배 조건 등 목록 | 명사형·해라체 | 董卓を討ち取る → 동탁을 쓰러뜨린다 |

### 2.1 인물 대사 말투

같은 상황의 대사가 화자 유형별로 이어진 항목에 나뉘어 있다(예: 정중형 → 남성 평어형 → 여성형 → 고풍형). 한 항목 안의 `.0 .1 .2`는 **무작위로 하나가 나오는 변형**이다. 원문의 어미로 말투를 판단해서 아래처럼 옮긴다. 같은 항목의 변형끼리는 말투를 맞춘다.

| 원문 말투 | 누가 | 한국어 |
|---|---|---|
| です・ます・ましょう・ございます | 신하가 군주에게, 정중한 말 | 합쇼체: `~습니다`, `~하시지요`, `~합시다` |
| だ・ぞ・う(意志)・〜ておこう・〜せよ | 군주·상급자·무장의 평어 | 하게체·해라체: `~일세`, `~하게`, `~하세`, 명령은 `~하라` |
| 〜でござる・〜申す・〜くだされ・〜ますぞ・〜じゃ・わし | 노장·노신·고풍 | 하오체: `~하오`, `~이오`, `~주시오`, `~하겠소`, `~구려` |
| わ・よ・ね・かしら・なさい | 여성 | 해요체 또는 여성적인 하오체: `~해요`, `~지요`, `~하세요`, `~하시오` |
| 〜てくれ・〜といい | 남성 평어 부탁 | `~해 주게`, `~하면 좋겠네` |
| 적에게·도발·분노 | | 해라체 반말: `~다!`, `~냐!`, `~거라!` |
| 오랑캐 왕·산적 등 거친 말 (〜だぜ・〜ぜ・俺様) | | 거친 반말: `~다고!`, `~거든!`, `이 몸` |

호칭: 殿(군주에게) → 주공, 陛下 → 폐하, 〇〇殿 → 〇〇 님(대사)·〇〇 공(격식), 〇〇様 → 〇〇 님, 兄者 → 형님, 父上 → 아버님, 母上 → 어머님, 我が君 → 주군, 貴様 → 네놈·이놈(상황에 맞게), 拙者/それがし → 소장·저(무인), 余 → 짐(황제)·나(군주), わし → 나(노인 말투는 어미로 살린다).

### 2.2 문장 다듬기

* 일본어 어순·표현을 그대로 옮기지 않는다. 한국어로 자연스럽게 말하는 문장으로 쓴다. (`〜のだ` → `~것이다`를 남발하지 않는다. `〜という` → 문맥에 맞게)
* 삼국지 관용 표현은 한국 삼국지에서 쓰는 말로: 桃園の誓い → 도원결의, 三顧の礼 → 삼고초려, 赤壁の戦い → 적벽대전, 天下三分の計 → 천하삼분지계, 苦肉の策 → 고육지책, 連環の計 → 연환계.
* `……`는 머뭇거림·여운에 쓴다(원문에 있을 때). `！` `？`는 반각 `!` `?`.
* 줄임표·감탄사 과잉, 인터넷 말투, 외래어 남용 금지.

## 3. 고유명사

* 인명·지명·관직·국호·아이템은 **한자의 한국 독음**으로 적는다(한국 삼국지 번역의 관례). 작업 파일의 「고유명사」 목록에 있는 것은 반드시 그 표기를 쓴다.
* **성씨와 지명 첫 글자에는 두음법칙을 적용**한다: 劉 유, 李 이, 呂 여, 盧 노, 陸 육, 凌 능, 廖 요, 雷 뇌, 梁 양, 婁 누, 樂 악(樂進)·낙(楽浪), 羅 나, 柳 유, 令 영, 洛 낙, 廬 여, 零 영, 臨 임, 隴 농, 琅 낭.
* 이름 둘째 글자 이하는 본음대로 적는다: 張遼 장료, 馬良 마량, 王朗 왕랑, 張魯 장로. 모음·ㄴ 받침 뒤의 列·烈·裂·劣 → 열, 律·率·栗·慄 → 율.
* 읽기가 둘 이상인 한자는 관례를 따른다: 賈 가(賈詡 가후), 單 선(성씨), 金 김(성씨)·금(金環三結 금환삼결), 樂 악(樂進)·낙(楽浪), 率 솔, 度 도(公孫度), 台 → 대(자·지명의 臺: 孫堅 字 文臺 문대, 陳宮 字 公臺 공대, 銅雀台 동작대), 涼州·揚州는 둘 다 양주.
* 자(字)도 한국 독음: 孔明 공명, 玄徳 현덕, 孟徳 맹덕, 雲長 운장, 翼徳/益徳 익덕, 子龍 자룡, 仲謀 중모, 公瑾 공근, 伯言 백언, 奉孝 봉효.
* 삼국지 밖 인물(열전의 역대 명장 등)도 한자 독음: 項籍 항적(項羽 항우), 劉邦 유방, 韓信 한신, 岳飛 악비, 管仲 관중, 成吉思汗 성길사한(칭기즈 칸), 蘭陵王 난릉왕. 몽골·서역 이름을 가나로 적은 것(テムジン 등)은 한국에서 통하는 표기로(테무친).
* 일본인 이름은 일본어 발음: 今戸榮一 이마도 에이이치.

## 5. 작업 방법

### 5.1 전체 흐름 (도구: `work/tools/`)
1. `make_central.py` — 인명·지명·아이템·관직·라벨 등 고유명사 블록 번역 → `trans/ko/units_central.tsv`
2. `convert_old.py` — 초반 테스트 번역을 단위 번역으로 옮김 → `trans/ko/units_old.tsv`
3. `make_jobs.py` — 남은 단위를 작업 파일로 나눔 → `trans/jobs/<작업>.txt`
4. 번역 → `trans/jobs/out/<작업>.tsv`, `check_job.py <작업>`으로 검사
5. `merge_jobs.py` — 결과를 `trans/ko/units/job_<작업>.tsv`로 합침
6. `build_all.py` — 모든 번역 검사·적용 → `work/patched/` (M_MSG.S9, M_RTDN.S9, SLPM_656.73)
7. `build_iso.py` — 원본 ISO 옆에 `San9PK_KR_test.iso` 생성, 에뮬레이터 확인

### 5.2 작업 파일 번역하는 법
* 작업 파일의 `@단위ID [종류 폭 줄수]` 아래가 원문이다. 줄바꿈은 원문 그대로 보인다.
* 결과는 한 줄에 한 단위: `단위ID<TAB>번역`. 번역의 줄바꿈은 `⏎`로 적는다.
  예) `M06071.0	{V:02DA} 님,⏎이번엔 신세를 지겠습니다⏎언젠가 꼭 갚지요`
* `(같은 원문 n곳)`은 한 번만 번역하면 모두 적용된다.
* 번역을 다 적은 뒤 `python work/tools/check_job.py <작업>`을 실행해 오류가 0이 될 때까지 고친다. 경고(변수 생략 등)는 의도한 것이면 두어도 된다.
* 원문이 이미 한국어로 옮길 필요가 없는 부분(숫자·기호만 있는 줄)은 그대로 둔다.

## 8. 동영상 자막 (2026-09-19 추가)

대상 34편: 시나리오 오프닝 `MOVIESOP/SOP_H00~H09`, `SOP_V00~V09`, 이벤트 `MOVIE/EVENT00~13`.
OPENING(자막 없음)·ENDING(제작진 명단)·KOEIINFO(광고)·THEME·LOGO 는 대상이 아니다.

### 8.1 모양

* 일본어 자막(화면 가운데, 글자 높이 약 20px, 아랫줄 바닥 y≈399)은 그대로 두고, 바로 아래(y≈406~)에 **한국어 한 줄**
* 글꼴: 본문과 같은 서울한강체 B, 13px(한글 높이 약 11px = 일본어의 절반 정도)
* 흰 글자 + 검은 외곽선(1.25px)만. 상자·그림자 없음. 화면 가운데 정렬
* 나타나고 사라지는 시점과 페이드는 일본어 자막의 밝기 변화를 프레임마다 재서 그대로 따른다

### 8.2 번역

* **한 줄만** — 폭 608px 이하(대략 한글 45자). 넘치면 줄이지 말고 문장을 다시 쓴다 (`movtrans.py`가 검사)
* 나레이션은 해라체 서술(`~했다`, `~한다`, `~이다`). 원문이 명사로 끝나면 한국어도 명사로 끝내도 된다(「軍師」を捜し求めるのだった → 「군사」를 찾고 있었다)
* 문장부호: 반각 `, . ! ?`, 낫표 「」 는 원문대로, `……`는 원문에 있을 때. 가운뎃점 `・`는 글꼴에 없으므로 `·`(「초·삼국지」)
* 연대 표기: `ときに西暦184年、漢の光和7年のことである` → `때는 서기 184년, 한나라 광화 7년의 일이다` (촉·위는 `촉나라 건흥 12년`, `위나라 함희 1년`)
* 고유명사·용어는 본문 번역과 같게: 황건적의 난, 반동탁 연합, 군웅할거, 연환계, 삼고초려, 적벽대전, 복룡, 융중, 오호장군, 한중왕, 낭야, 왜, 모살(謀殺)
* 두 카드에 걸친 한 문장(예: `劉備、関羽、張飛。死ぬときは同じと誓った3人は、` / `…反乱鎮圧軍に参加した。`)은 카드마다 따로 읽혀도 자연스럽게 끊는다

### 8.3 작업 흐름 (도구: `work/tools/`)

1. `subdetect.py` — 영상에서 일본어 자막 카드(구간·프레임별 불투명도·대표 프레임)를 찾아 `work/movie/subs/<이름>.json`, 받아쓰기용 `crops/`
2. `subsheet.py 출력.png 이름…` — 카드 모음 이미지로 일본어를 받아 적는다(기계 판독·기계 번역 쓰지 않음)
3. `trans/ko/movie/src/*.txt` 에 `[이름]` 다음 카드 순서대로 `일본어<TAB>한국어` → `movtrans.py 파일` 이 `trans/ko/movie/<이름>.tsv` 로 기록하며 카드 수·폭·부호 검사
4. `subpreview.py 출력.png 이름…` — 인코딩 없이 대표 프레임에 한국어 줄을 그려 확인
5. `movenc.py all` — 자막을 그린 프레임을 고정 양자화 14벌(닫힌 GOP 18장, I 위치 원본과 같음, B 2장)로 인코딩하고 `gopsplice.py` 가 GOP 마다 원본 패킷 일정(최대 4프레임 지연)에 맞는 벌을 골라 이어 붙인 뒤 `psmux.py` 가 원본 PSS 틀에 다시 넣는다 (예전 1패스 CBR 은 I 프레임을 굶겨 0.6초마다 화질이 출렁였음 — 2026-09-19 사용자 지적으로 바꿈):
   음성 패킷·팩 헤더는 원본 그대로(바이트 동일), 영상 패킷 자리만 새 영상으로 채우고 PTS/DTS 재계산, 원본 일정보다 3프레임 넘게 앞서면 패딩 패킷. 결과 파일 크기 = 원본 → 파일 테이블·ISO 위치 수정 없음
6. 결과 `work/patched/MOVIE/*.PSS`, `work/patched/MOVIESOP/*.PSS` → `build_iso.py` (`--check` 로 먼저 검사)
