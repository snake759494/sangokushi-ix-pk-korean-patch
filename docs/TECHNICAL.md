# 기술 설명

PS2 일본판 「三國志IX with パワーアップキット」(SLPM-65673)의 데이터 구조와 이 패치가 바꾼 방식을 정리합니다. 오프셋은 따로 적지 않으면 파일 오프셋이고, `VA` 는 실행파일의 가상 주소(파일 오프셋 − 0x80 + 0x100000)입니다.

## 1. 디스크 구성

| 파일 | 위치 | 내용 |
| --- | --- | --- |
| `SLPM_656.73` | LBA 446, 3,751,728 B | 실행파일. 문자열·그림 블록 위치표·파일 테이블 포함 |
| `SAN9PK.BIN` | LBA 1,100,000, 44,079,104 B | 헤더 없는 묶음 파일. 글꼴(`F_FONT.S9`), 텍스트(`M_MSG.S9`, `M_RTDN.S9`), 그래픽(`G_*.S9`) 등 |
| `MOVIE/*.PSS`, `MOVIESOP/*.PSS` | 각자 ISO 위치 | 동영상 39편(이벤트 14, 시나리오 오프닝 20, 오프닝·엔딩·로고 등 5) |
| `GR_TRI1/`, `GR_TRI2/` | ISO 폴더 | 트라이얼 스토리 스테이지 제목 그림 34장 (`G_PH*.S9`) |
| 빈 영역 | LBA 1,121,523 ~ 1,124,999 | 원본에서 모두 0. 커진 텍스트 파일을 옮겨 두는 곳 |

게임은 `SAN9PK.BIN` 안 파일과 동영상을 실행파일의 **파일 테이블**(0x32D130, 32바이트 항목 `[이름 포인터, 0, 시작 LBA, 0, 끝 LBA, 0, 섹터 수, 0]`)로 찾아 읽습니다. 그래서 크기가 바뀌는 파일은 테이블의 LBA·섹터 수와 읽기 크기 상수를 함께 고쳐야 하고, 크기가 같은 파일은 제자리에 덮어씁니다(`work/tools/build_iso.py`).

## 2. 글꼴

`F_FONT.S9` 는 앞머리에 Shift-JIS 코드표(u16 개수 + 코드)가 있고 0xAD60 부터 24×24 4bpp 전각 글리프 3,758자가 이어집니다. 게임 글자 간격은 전각 22px, 반각 11px 입니다.

한글은 **KS X 1001 완성형 2,350자**를 한자 슬롯 `亜`(SJIS 0x889F)부터 0x94FC 까지에 차례로 덮어썼습니다(`work/tools/font_build_ko.py`, 서울한강체 B 22px). 코드 ↔ 한글 대응표는 `work/font_ko/hangul.tbl` 입니다. 번역문을 게임 텍스트로 바꿀 때 한글은 이 표의 SJIS 코드로, 반각 문자와 기호는 원래 코드로 인코딩합니다. 이 때문에 번역문에는 한자·가나를 쓸 수 없습니다(그 슬롯이 한글로 보임).

이름 읽기(루비)는 반각 가나 전용의 작은 글꼴로 그려져 한글을 표시할 수 없어 비웠습니다. **단, 무작위 무장의 성·이름 읽기 표(M_MSG 0x3938~0x399F, 0x3B7B~0x3D55)는 원본 그대로 둡니다.** 게임은 병사 발탁 등으로 무장을 만들 때 두 읽기를 이어 붙이고(ELF 0x213EC0) 길이가 0 이거나 11 이상이면 이름을 다시 뽑는데(ELF 0x3B4EA0), 읽기를 비우면 이 재시도가 끝나지 않아 게임이 멈춥니다(v1.0~v1.0.2 의 프리징). `work/tools/build_all.py` 의 `KEEP_ORIGINAL_MSG` 가 이 표에 번역을 넣지 않게 막습니다.

## 3. 텍스트 (`M_MSG.S9`, `M_RTDN.S9`)

두 파일 모두 `u16 항목 수` + `u32 오프셋 표` + 본문 구조입니다. `M_MSG.S9` 16,012항목(메뉴·대사·도움말·시나리오 개요 등), `M_RTDN.S9` 720항목(무장 열전).

본문은 텍스트 바이트와 스크립트 명령이 섞여 있어 `work/tools/s9lex.py` 로 토큰을 나눕니다. 번역 파일에서는 다음 태그로 적습니다: `{V:xxxx}` 이름·숫자 변수, `{C:..}` 글자 색, `{U:F0xx}` 버튼 아이콘·전용 글리프, `{ESC:H}` `{ESC:K}` `{ESC:k}` 가나 모드, `⏎` 줄바꿈. 일본어가 들어 있는 텍스트 토막을 **번역 단위**로 뽑아(`work/tools/units.py`) 모두 21,727단위를 번역했습니다. 단위마다 화면 종류(대사창·도움말·개요·열전·라벨 등)에 따라 한 줄 폭과 줄 수 한계를 두고 빌드 때 검사합니다(`docs/BUILD.md`, `work/trans/번역규칙.md`).

번역하면 두 파일이 커지므로 원래 자리(SAN9PK 안)에 들어가지 않습니다. 빈 영역으로 옮겼습니다.

| 파일 | 원래 할당 | 새 위치 · 할당 | 고친 곳 |
| --- | --- | --- | --- |
| `M_MSG.S9` | 0xD6800 | LBA 1,121,523 · 0x102000 | 파일 테이블 8번 항목, 읽기 크기 `lui/ori` 3쌍 (VA 0x1535CC/0x1535E8, 0x21104C/0x211054, 0x20FDD4/0x20FDE0) |
| `M_RTDN.S9` | 0x14000 | 그 뒤 · 0x18000 | 파일 테이블 9번 항목, `lui/ori` 3쌍 (VA 0x153604/0x153618, 0x211048/0x211050, 0x20FDD0/0x20FDDC) |

## 4. 실행파일 문자열

메뉴 항목·표 머리글·짧은 메시지 등 1,147곳을 **원래 자리에서** 바꿨습니다(`translation/elf_strings.tsv`). 새 문자열은 원래 NUL 과 정렬 여백까지의 바이트 안에 들어가야 하고, `printf` 서식 지정자(`%d`, `%3d` …)와 색·반전 제어 코드(`ESC[25b`, `ESC[30m` …)는 순서까지 그대로 둡니다(`work/tools/build_all.py` 가 검사).

전체 번역 뒤 사용자 스크린샷으로 빠진 문자열을 찾았습니다. 반각 가나가 섞인 문자열(`ﾀｲﾄﾙ画面`), ESC 제어 코드가 든 문자열(`到着予定`, 아이템 유래의 인물 이름), 3자 이하 문자열(`兵法P`)이 추출 필터에 걸려 빠져 있었습니다. 이들은 `work/trans/ko/elf/02_missed.tsv` 에 모았습니다.

## 5. 그래픽

### 5.1 압축 블록 (`G_*.S9`)

그래픽 파일 대부분은 LZSS 블록의 모음입니다. 블록 = `[u32 종류][u32 풀린 크기][u32 코드 위치][u32 리터럴 위치]` + 플래그(u64, 최상위 비트부터, 1 = 리터럴 한 바이트, 0 = 복사) + 복사 코드(u16) + 리터럴. 종류 t 는 창 크기 2^(10+t) 바이트를 뜻하고, 복사 코드는 `pos = v & (창 − 1)`, `len = (v >> (10+t)) + 3` 입니다. 게임의 해제 함수(VA 0x23CAA0 → 종류별 0x23C6E0/7D0/8C0/9B0)는 **출력 크기를 검사하지 않고 `pos == 0` 코드에서만 멈춥니다.** 끝 코드가 없으면 버퍼를 넘어 RAM 의 한글 글꼴을 덮어써 메뉴 글자가 깨집니다. 새 압축기(`work/tools/s9lz.py`, `work/tools/title/s9enc.py`)는 항상 끝 코드를 쓰고, 만든 블록을 게임 해제 함수의 모형(`work/tools/title/gamedec.py`)으로 되풀어 확인합니다. 블록 위치는 실행파일의 표에 고정된 경우가 많아 모든 블록을 원래 자리에 넣고 남는 곳은 0 으로 채웠습니다.

### 5.2 바꾼 그림

| 그림 | 파일 · 위치 | 한 일 |
| --- | --- | --- |
| 타이틀 로고 | `G_TITLE.S9` 10블록 (위치표 VA 0x4611D0) | 「パワーアップキット」 아래에 「파워업키트」 캡션. 바탕 그림과 빛 번짐 애니메이션 8장, PRESS START 5장에 모두 그림(덮어 그려지므로). 팔레트 255번을 흰색으로 |
| 전략·진행 페이즈 배너 | `G_MAPGRP.S9` 0x847F0 묶음 4블록 (묶음 시작 VA 0x2F7684, 블록 위치표 0x2F76D0 = 0, 0x3180, 0x7A10, 0xAAC0) | 「전략 페이즈」「진행 페이즈」 |
| 트라이얼 스토리 스테이지 제목 34장 | `GR_TRI1/`, `GR_TRI2/` 의 `G_PH*.S9` (두 번째 블록 위치표 0x392720~) | 「설욕전」「적벽대전」「스테이지 클리어」「시간 초과」 등 |
| 능력 그래프 | `G_SYSTEM.S9` 0x102000 (8비트, 폭 256, 200×104) | 統率·武力·政治·知力 → 통솔·무력·정치·지력 |

배너는 256×256 블록 하나가 512×128 배너의 왼쪽(윗 128줄)·오른쪽(아랫 128줄) 절반이고, 글자+빛 층과 테두리 층 두 블록이 겹쳐 그려집니다. 원본 두 층에서 글자 획까지의 부호 있는 거리와 밝기의 관계를 재고, 서울한강체 EB 로 쓴 한국어 글자에 같은 관계를 적용해 두 층을 새로 만들었습니다(`work/tools/gfx_banner.py`). 원본의 붓글씨 대신 고딕 글꼴이지만 빛·테두리 모양은 원본과 같습니다.

능력 그래프는 같은 그림을 색 팔레트(무장 선택 뒤)와 회색 팔레트(선택 전)로 그립니다. 두 팔레트는 에뮬레이터의 VRAM 에서 떠 두었고(`work/gfx/radar_cluts.npz`), 옛 글자를 주변 배경으로 지운 뒤 한국어를 그리고 두 팔레트 모두에서 목표 색에 가장 가까운 번호를 골랐습니다(`work/tools/gfx_radar.py`).

## 6. 동영상 자막

### 6.1 PSS 구조

MPEG-2 프로그램 스트림입니다. 16 KB 팩마다 PES 패킷 4개(4082/4096 바이트)가 들어 있고, 영상은 스트림 E0(MPEG-2 MP@ML 640×448, 30fps, 순차 주사, CBR 3000 kbps, VBV 917,504비트, GOP 18장, B 2장), 음성은 사설 스트림 BD(PS2 ADPCM 스테레오 44.1 kHz)입니다.

### 6.2 자막

자막이 있는 34편(시나리오 오프닝 `SOP_H00~09`, `SOP_V00~09`, 이벤트 `EVENT00~13`)의 일본어 자막 268장에 한국어 한 줄을 덧붙였습니다.

1. `subdetect.py` — 프레임마다 '밝고 가늘고 무채색이며 가까이에 어두운 테두리가 있는' 글자 획을 찾아 자막 카드의 구간·프레임별 불투명도(페이드)를 잽니다 → `work/movie/subs/*.json`.
2. 일본어를 사람이 받아 적고 번역해 `work/trans/ko/movie/*.tsv` 에 적습니다(`translation/movie_subtitles.tsv`).
3. `subrender.py` — 서울한강체 B 13px(한글 높이 약 11px, 일본어의 절반 정도), 흰 글자 + 검은 외곽선, 일본어 자막 아래 가운데. 불투명도는 일본어 자막의 페이드를 그대로 따릅니다.

### 6.3 재인코딩과 다시 묶기

자막을 합성한 프레임을 다시 MPEG-2 로 인코딩하고, **원본 PSS 의 틀을 그대로 두고 영상 패킷 자리만 새 영상으로 채웁니다**(`psmux.py`). 음성 패킷·팩 헤더는 바이트 단위로 원본과 같고, 파일 크기도 같아서 디스크 위치와 파일 테이블을 고칠 필요가 없습니다. PTS/DTS 는 새로 계산하고, 새 영상이 원본 일정보다 3프레임 넘게 앞서면 그 자리를 패딩 패킷으로 채웁니다.

인코딩은 `movenc.py` + `gopsplice.py` 입니다. 처음에 쓴 ffmpeg 1패스 CBR 은 VBV 에 묶여 I 프레임을 굶겼고(원본 평균 67 KB → 15 KB), 0.6초마다 화질이 출렁였습니다(v1.0 전 내부 빌드, 사용자 지적). 지금 방식은 다음과 같습니다.

- 같은 GOP 구조(닫힌 GOP 18장, I 위치 원본과 같음, B 2장)로 고정 양자화 q 14가지(1.6 ~ 12)를 모두 인코딩합니다. GOP 안은 고정 q 라 I/P/B 배분이 원본과 비슷합니다(평균 I 약 45 KB, P 13 KB, B 5 KB).
- GOP 마다 원본 패킷 자리에 넣어 보며 **원본 일정보다 4프레임 넘게 늦지 않는** 벌을 고릅니다. 이번 GOP 와 다음 GOP 중 더 거친 쪽이 가장 곱게 되도록 고르고(어려운 장면 앞에서 미리 여유를 만듦), 이웃 GOP 사이 q 변화를 제한합니다.
- 시퀀스 헤더의 비트율·VBV 크기 필드는 원본 값으로 맞춥니다.

EVENT05 기준, 원본 대비 PSNR(자막 띠 제외)은 CBR 때 평균 41.0 / 최저 31.5 dB 에서 42.5 / 39.2 dB 로 올랐고, I 프레임으로 넘어갈 때 원본에 없는 밝기 변화(깜박임)는 절반으로 줄었습니다(`validation/movie_quality.md`).

## 7. 손대지 않은 것

- 메인 메뉴 왼쪽 위의 작은 로고(`G_START1.S9`): 캡션 넣을 빈자리가 없어 실행파일의 스프라이트 정의를 고쳐야 합니다.
- 자막 나레이션이 없는 동영상: 오프닝(OPENING), 엔딩 제작진 명단(ENDING), 광고(KOEIINFO), LOGO, THEME. 인트로의 「歴史シミュレーションゲーム」 같은 그림 글자.
- 메모리카드 저장 파일 이름(「三国志９ｗＰＫプレイデータ」): PS2 본체 화면이 자체 글꼴로 그리므로 한글이 나오지 않습니다.
- 이름 입력판의 가나 배열.
