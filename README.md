# 삼국지 IX with 파워업키트 PS2 한글패치

PS2 일본판 **三國志IX with パワーアップキット (SLPM-65673)**용 비공식 한국어 패치입니다. 게임 안 텍스트 전부(메뉴·도움말·용어사전·시나리오 개요·튜토리얼·인물 대사·이벤트·무장 열전), 실행파일의 문자열, 그림 글자(타이틀 캡션·페이즈 배너·트라이얼 스테이지 제목·능력 그래프)를 한국어로 바꾸고, 동영상 34편의 일본어 자막 아래에 한국어 자막을 넣었습니다. 현재 배포판은 **v1.0.2 (2026-09-20)**입니다.

[패치 다운로드](https://github.com/snake759494/sangokushi-ix-pk-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 두 가지이고 **둘 중 하나만** 받으면 됩니다. 둘 다 같은 원본 ISO 에 적용합니다.

| 파일 | 내용 | 크기 |
| --- | --- | --- |
| `Sangokushi_IX_PK_KO_v1.0.2.xdelta` | 전체판 (동영상 한국어 자막 포함) — 권장 | 712 MB |
| `Sangokushi_IX_PK_KO_v1.0.2_nomovie.xdelta` | 동영상을 바꾸지 않는 가벼운 판 (자막 외 나머지는 같음) | 1.7 MB |

저장소에는 제작 소스·번역·검증 자료를 공개합니다. 원본 및 완성 ISO, 게임에서 추출한 파일, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub 가 자동 생성하는 Source code ZIP/TAR 는 저장소 소스의 압축본이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

「삼국지 IX」는 코에이의 역사 시뮬레이션 「삼국지」 시리즈 아홉 번째 작품입니다. 중국 전토를 한 장의 지도로 보며, 모든 세력이 명령을 내리는 **전략 페이즈**와 그 명령이 동시에 실행되는 **진행 페이즈**가 번갈아 흘러갑니다. 부대의 진형과 무장의 병법, 병법 연쇄가 전투의 핵심입니다. 「with パワーアップキット」판에는 기한 안에 목표를 이루는 **챌린지 시나리오**, 조씨·손씨·유씨의 이야기를 스테이지로 따라가는 **트라이얼 스토리**, IF 시나리오, 신무장·신아이템 등록과 무장 편집이 더해져 있습니다.

이 패치는 **PS2 일본판 SLPM-65673** 에만 적용합니다. PC판이나 다른 기종판에는 쓸 수 없고, 같은 PS2 판이라도 아래 크기·해시가 다르면 적용하지 마세요. 파일 이름보다 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows 에서 원본 확인

PowerShell 에서 실제 파일 경로를 넣어 실행합니다.

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Sangokushi IX with Power-Up Kit (Japan).iso'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Sangokushi IX with Power-Up Kit (Japan).iso'
```

위 표와 다르면 적용을 중단하고 원본 버전 및 파일 상태를 확인하세요. CHD·CSO·BIN/CUE 를 ISO 처럼 이름만 바꿔서는 사용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 xdelta 파일 하나를 받습니다(전체판 권장).
2. xdelta3 패치를 지원하는 도구의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 ISO 를 선택합니다.
4. **Output File** 에 원본과 다른 새 파일명, 예를 들어 `Sangokushi IX with Power-Up Kit (Korean v1.0.2).iso` 를 지정합니다.
5. 적용 완료 후 결과 ISO 의 SHA-256 을 위 표와 비교합니다.

호환성을 위해 xdelta 는 2차 압축과 파일 경로 헤더 없이 만들었습니다. UI 명칭은 도구마다 조금 다릅니다. 외부 도구 실행 파일은 이 릴리즈에 포함하지 않습니다. xdelta 자체의 소스와 배포 안내는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Sangokushi IX with Power-Up Kit (Japan).iso' '.\Sangokushi_IX_PK_KO_v1.0.2.xdelta' '.\Sangokushi IX with Power-Up Kit (Korean v1.0.2).iso'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Sangokushi IX with Power-Up Kit (Korean v1.0.2).iso'
```

원본·패치·결과의 해시를 자동 검사하는 도구도 있습니다. Python 3 과 xdelta3 실행 파일을 준비한 뒤 저장소 루트에서 다음처럼 사용합니다(두 배포 파일 모두 지원).

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\Sangokushi IX with Power-Up Kit (Japan).iso' --patch '.\Sangokushi_IX_PK_KO_v1.0.2.xdelta' --output '.\Sangokushi IX with Power-Up Kit (Korean v1.0.2).iso'
```

이 도구는 기존 출력 파일을 덮어쓰지 않습니다. 패치 적용 실패나 결과 해시 불일치 시 성공으로 처리하지 않습니다.

### PCSX2 에서 실행

게임을 완전히 종료한 뒤 새 ISO 를 여세요. 패치판은 실행파일과 텍스트 파일의 배치가 원본과 다르므로 **원본판의 세이브 스테이트를 불러오지 마세요.** 이어 하기는 게임 안 메모리카드 저장으로 하세요. 원본판 메모리카드 세이브를 패치판에서 불러오는 것은 별도로 검증하지 않았습니다. PS2 브라우저·PCSX2 메모리카드 화면에 보이는 세이브 이름은 본체 글꼴로 그려지므로 일본어 그대로입니다.

번역은 자동 번역기(번역 서비스)를 쓰지 않았고, 규칙 문서 [work/trans/번역규칙.md](work/trans/번역규칙.md) 에 따라 단위마다 문맥·화자·화면 폭을 보고 새로 썼습니다. 인명·지명·관직은 한국 삼국지 번역의 관례대로 한자의 한국 독음으로 적었고(도원결의·삼고초려·적벽대전 등 관용 표현 포함), 용어는 UI 표기와 설명문을 일치시켰습니다. 신하→군주는 합쇼체, 군주·무장의 평어는 하게체·해라체, 노장은 하오체 등 원문의 말투를 옮겼습니다. 사람이 읽는 대역표는 [translation/](translation/)(`script.tsv` 21,727행, `elf_strings.tsv`, `movie_subtitles.tsv`)에 있습니다.

게임에는 이름·숫자가 들어가는 변수 뒤에 받침에 따라 바뀌는 조사를 고를 방법이 없어, 변수 바로 뒤에는 받침과 무관한 조사만 쓰거나(「의·에게·에서」) 「~ 장군이」「~군은」처럼 말을 덧붙였습니다. 대사창은 한글 14자, 3줄마다 쪽이 넘어가는 원문 구조를 지켰습니다.

## 검증 범위와 제한

- 원본 ISO → xdelta → 결과 ISO 의 SHA-256 이 배포용 완성 ISO 와 일치(두 판 모두).
- 저장소의 소스와 번역 데이터만으로 원본 ISO 에서 다시 빌드해 글꼴·텍스트·실행파일·그림 파일 41개가 배포판과 바이트 단위로 같음을 확인. 동영상 단계는 같은 스크립트로 만들었습니다(`validation/`).
- 빌드 검사: 번역 단위 21,727/21,727, 오류 0(폭·줄 수·태그·변수 뒤 조사·완성형 밖 글자). 텍스트 파일에 남은 일본어 0.
- 압축 그림 블록은 게임 해제 함수의 모형으로 되풀어 풀린 크기·끝 코드를 확인. 블록 위치는 실행파일의 위치표와 같게 유지.
- 동영상은 원본 대비 화질·깜박임을 측정([validation/movie_quality.md](validation/movie_quality.md)). 음성 패킷과 파일 크기는 원본과 같음.
- PCSX2 2.2.0 에서 타이틀·메인 메뉴, 시나리오 선택·개요, 세력 선택·설정, 오프닝 동영상 자막, 전략/진행 페이즈 배너, 커맨드 메뉴와 순찰·수송·출진·등용 창(능력 그래프, 도착예정), 대사창, 도움말, 무장 열전, 챌린지 시나리오, 트라이얼 스토리 스테이지 제목과 클리어 조건을 화면으로 확인했습니다([validation/runtime_test.md](validation/runtime_test.md)).

**전 시나리오 완주·엔딩·실기 PS2 검증은 하지 않았습니다.** 조작 안내 「START 타이틀」(모든 세력을 컴퓨터가 움직일 때의 안내)은 문자열을 바이트로 확인했지만 그 화면을 다시 띄워 보지는 못했습니다. 이벤트 동영상은 게임 안 발생 조건을 모두 재현하지 못해 한 편을 다른 슬롯에 넣어 재생해 보는 방식으로 확인했습니다.

오류 제보에는 패치 버전(전체판/동영상 제외판), 결과 ISO SHA-256, PCSX2 버전, 시나리오·화면·재현 순서와 스크린샷을 적어 주세요. 게임 ISO 나 추출 바이너리는 이슈에 첨부하지 마세요.

## 저장소 구성 및 권리

- `work/tools/`: 빌드 도구. 원본 추출(`extract_originals.py`), 텍스트 코덱·토큰 분석(`s9text.py`, `s9lex.py`), 번역 단위와 폭 규칙(`units.py`, `validate.py`), 텍스트·실행파일 빌더(`build_all.py`), 글꼴(`font_build_ko.py`), 그림 압축(`s9lz.py`, `title/`), 배너·능력 그래프(`gfx_banner.py`, `gfx_radar.py`), 동영상 자막(`subdetect.py`, `subrender.py`, `movenc.py`, `gopsplice.py`, `psmux.py`, `pss.py`), ISO 빌더(`build_iso.py`), 배포 파일(`make_release.py`), 대역표(`export_tables.py`).
- `work/trans/`: 빌드 입력 번역 파일(`ko/units/*.tsv`, `ko/elf/*.tsv`, `ko/movie/*.tsv`, 용어·라벨 사전)과 번역 규칙.
- `work/font_ko/hangul.tbl`: 한글 ↔ 게임 코드 대응표. `work/movie/subs/*.json`: 동영상 자막 구간·페이드. `work/gfx/radar_cluts.npz`: 능력 그래프 팔레트.
- `translation/`: 사람이 읽는 대역표 TSV.
- `tools/apply_release.py`: 배포 패치 적용·해시 검사.
- `docs/`, `validation/`: 기술 설명, 재빌드 절차, 글꼴 출처, 검증 기록.

원작 게임의 권리는 코에이테크모게임스에 있습니다. 이 프로젝트는 공식 한국어판이 아니며 권리자의 지원·승인을 뜻하지 않습니다. 전체판 xdelta 에는 한국어 자막을 합성해 다시 인코딩한 동영상 데이터가 들어 있습니다. 게임 안 한글과 그림 글자는 서울한강체(서울특별시)로 만들었고 글꼴 파일은 재배포하지 않습니다. [글꼴 출처](docs/FONT_CREDITS.md)와 [권리 안내](RIGHTS.md)를 참고하세요.
